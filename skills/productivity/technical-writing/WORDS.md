# Words

## Frequent errors

Replace the word on the left with the word or wording on the right.

| Avoid | Use |
|---|---|
| acceptable (adj) | permitted (adj) |
| alternate (adj) | alternative (adj) |
| any (adj) | No word, or a different sentence construction |
| avoid (v) | prevent (v) |
| both (adj) | the two |
| check (v) | check (n): "do a check of" |
| complete (adj) | completed (adj) |
| cover (v) | cover: "put a cover on" |
| damage (v) | damage (n): "cause damage to" |
| ensure (v) | make sure (v) |
| fit (v) | install (v) |
| follow (v), for instructions | obey (v) |
| further (adj, adv) | more (adj, adv) |
| have to (v) | A command: start with the verb |
| however (adv) | but (conj) |
| insert (v) | put (v) |
| main (adj) | primary (adj) |
| may (v) | can (v) |
| need (v) | necessary (adj) |
| now (adv) | at this time |
| old (adj) | remaining, used, or expired (adj) |
| over (prep) | above, on, or along (prep) |
| people (n) | person (n), personnel (n) |
| perform (v) | do (v) |
| portion (n) | part (n) |
| press (v) | push (v) |
| reach (v) | get (v) |
| repeat (v) | do (v) ... again |
| required (v) | necessary (adj) |
| rotate (v) | turn (v) |
| secure (v) | attach (v), lock (v) |
| shall (v), should (v) | must (v) |
| since (conj) | because (conj) |
| test (v) | test (n): "do a test of" |
| therefore (adv) | thus (adv), as a result |
| under (prep) | below (prep), in (prep), less than |
| using (v) | use (v), with (prep) |

Exception: "press", "click", "type", and "enter" are correct for keys, buttons, and input fields.

## More words to replace

Use these replacements in all text. A field verb (see SKILL.md) is correct with its field meaning: "Delete the branch" and "Save the file" are correct.

### Verbs

| Avoid | Use |
|---|---|
| allow, permit, enable (for a result) | let: "This flag lets the job continue" |
| approve | give approval |
| ask | tell, speak to: "Speak to the owner of the service" |
| assume | think |
| attempt | try |
| begin, initiate, trigger | start |
| build (v) | make. "The build" is a field term. |
| choose, decide | select |
| comply with | obey |
| comprise | have, contain |
| convert, modify | change |
| create, generate, produce | make, give, supply |
| define | give, specified (adj) |
| describe, mention | give: "This section gives the steps" |
| detect | find |
| determine | find, calculate, select |
| display (v) | show |
| end, finish (v) | stop, complete |
| execute, implement | do. For a command: run. |
| exist | be: "There is a lock file" |
| expect | possible (adj): "It is possible that the job stops" |
| explain | tell |
| affect, impact | change, have an effect on |
| fail | if ... not: "If the build does not complete" |
| fix | repair, correct |
| handle | use, move, or the accurate action |
| happen | occur |
| inspect, search | examine |
| list (v) | show, record |
| locate | find |
| log, note (v) | record |
| match | agree with, align |
| notify, alert, warn | tell |
| obtain | get |
| omit, exclude, skip | do not include |
| protect | prevent: "This lock prevents duplicate writes" |
| provide | give, supply |
| raise | increase, lift |
| reduce | decrease |
| request (v) | tell, write to |
| require | necessary (adj): "A token is necessary" |
| reset, restart | set ... again, start ... again |
| result in | cause |
| run (for a service or machine) | operate: "The service operates on port 80". For commands, tests, and jobs, run is a field verb. |
| solve | find a solution to |
| state (v) | tell |
| transfer | move |
| utilize | use |
| verify | make sure that |
